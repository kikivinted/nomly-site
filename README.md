# nomly-site

Site de Nomly — sites internet pour les artisans de la région nantaise.

- Branche `main` : page de maintenance (« Le site arrive bientôt »), en ligne sur l’hébergement gratuit OVH (dossier `www`, envoi par FTP).
- Branche `site-final` : le vrai site (accueil, créateur de démo, pages légales), à fusionner dans `main` le jour du lancement.

Site 100 % statique (HTML/CSS/JS), aucun build nécessaire.

Hébergement : OVH (hébergement gratuit inclus avec le nom de domaine). Pour mettre à jour : envoyer les fichiers .html de la branche voulue dans le dossier `www` par FTP.
